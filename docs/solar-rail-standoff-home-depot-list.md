# Solar Rail Standoff Home Depot List

Date: 2026-06-20. Quick in-store shopping list for the NXT rail spacer/isolation stack. Spreadsheet copy: [solar-rail-standoff-home-depot-list.csv](solar-rail-standoff-home-depot-list.csv).

This list does **not** change the solar mounting verdict: the hard spacer is aluminum, the rubber is only isolation/bedding, and the structural load path is still rail -> fastener -> roof bow. Use short interrupted pads at roof-bow stations, not a continuous strip under the rail.

## Preferred Stack

```text
NXT rail
stainless bolt + bonded sealing washer
1/4 in aluminum spacer pad
thin dense rubber isolation/gasket pad, if acceptable
controlled bedding/sealant layer
roof skin
steel roof bow
backing washer/plate/crush control
nylock nut
```

## Black Self-Adhesive Rubber Pad Rule

Buy it only if it feels like dense solid rubber, not foam. Treat it as a removable assembly aid and isolation layer:

```text
aluminum pad
black rubber pad stuck to aluminum
thin bedding/sealant
roof skin
```

Do not stick it directly to the roof as the only weather seal, and do not let it replace the 1/4 in aluminum spacer.

## Store Decision

If the store does not have dense solid rubber, buy the aluminum bar, stainless hardware, anti-seize, and Henry 884 at Home Depot. Order real 1/16 in 60A EPDM/neoprene strip separately, or cut gaskets from a roof-rated rubber pipe boot if the store has one.

For the current in-store bolt buy, assume **1.75 in stack thickness** and use **2-1/2 in stainless bolts**. Do not buy 2 in bolts for this stack.
